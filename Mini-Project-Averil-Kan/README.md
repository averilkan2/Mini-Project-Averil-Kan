# DM2008-Averil-Kan-AY2627-S1 - Mini Project
## Flappy Bird

This sketch is called 'Floppy Fish', a different version of the classic Flappy bird game but set underwater with our main guy being a fish instead of a bird.

## How it works
- Press 'P' to start play
- Press 'Spacebar' to jump/flop up
- When game is over, Press 'ENTER' to restart
- avoid the seabed and the pipes as you navigate through the waters
- The game continues as new pipes spawn

## Features
- a simple fish that moves
- pipes generated at random heights with consistent gaps
- continuous background, fish and pipes
- built using classes and arrays to keep code organised
- Score counter as each pipe has been passed by the fish
